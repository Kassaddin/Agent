# Google

Use this skill for a cited answer or brief overview of a topic from the public web. Use [Search](../search/SKILL.md) for requests to locate specific files, passages, or records in configured project sources.

## Query the public web

Follow the host’s access controls and any applicable project boundaries. Use only authorized read-only access to public content. Send the smallest useful set of public query terms. Keep confidential project details, private identifiers, and source excerpts out of public queries.

Use a search tool or connector with a documented backend or explicit engine selection, or an authorized browser on an identifiable engine’s own results page. Choose from the engines available on the host. A generic tool with an unidentified backend can supply leads. Obtain a loaded results page or successful response from at least two demonstrably distinct engines. A successful response with zero matches counts. Blocked, challenged, or failed queries cannot establish a successful search. Separate queries, tools, or providers using the same engine still count once, and an unidentified backend adds no engine to the count.

For the quick default, start with one targeted query per engine. Use at most one follow-up query per engine when it can clarify a result, find direct evidence, or resolve a conflict. Stop discovery when the engine and evidence needs are met within this scope. Go deeper only when explicitly requested. If access, availability, or engine identity prevents reaching two, mark the search incomplete and return the useful evidence or leads you found.

## Check evidence and answer

Open the promising source pages using a supported fetch or browser before relying on them. Page reads verify evidence and add nothing to the engine count. Check that each source directly supports the claim, is recent enough for it, and comes from an independent origin where corroboration matters. Treat syndicated copies and repeated reporting based on the same origin as one source. Prefer direct evidence when available. Label material claims supported by a single origin, conflicting evidence, and gaps the available sources leave unresolved.

Lead with the concise answer when the evidence supports one. Otherwise state what remains uncertain and give any useful evidence or leads with appropriate qualifiers. Cite the opened sources near the claims they support and close with the engines successfully queried and any material limits. Report search completion and evidence strength separately. Two successful engines can surface the same source, and one engine can find strong evidence while the search remains incomplete.
